Methodology & Pipeline Architecture

NeuroDetect utilizes advanced functional connectivity analysis on resting-state fMRI data to detect early-stage biomarkers of Parkinson's Disease with high clinical confidence.

1. Data Source

Scans are sourced from the PPMI (Parkinson's Progression Markers Initiative). We utilize 4D NIfTI volumes which represent the blood-oxygen-level-dependent (BOLD) signal over time.

2. Signal Extraction

Using the MSDL Atlas and Nilearn, we extract time-series data from 39 functionally defined brain regions, focusing on the basal ganglia and cortical networks.

3. Connectivity Analysis

We calculate Tangent Space Connectivity matrices. Unlike simple correlation, tangent embedding captures the underlying geometry of the connectivity manifold, improving group separation.

4. Machine Learning

Classification is performed via a Support Vector Machine (SVM) with an RBF kernel, optimized with Feature Selection (SelectKBest) to identify the most discriminative neural pathways.

Scientific Significance

This automated pipeline reduces diagnostic subjectivity and provides neurologists with a quantitative "Confidence Score" based on objective functional biomarkers rather than purely clinical observation.
